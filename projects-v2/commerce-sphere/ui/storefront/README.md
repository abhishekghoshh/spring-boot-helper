# CommerceSphere Storefront

Customer-facing React 19 storefront for browsing and purchasing products.

## Pages
- Home (with featured products)
- Product Listing & Detail
- Category Landing
- Search Results
- Shopping Cart & Wishlist
- Checkout & Order Confirmation
- Order History & Detail
- Login, Register, Forgot Password
- My Account

## Running Locally
```bash
cd ui/storefront
npm install
npm run dev
```

Access at http://localhost:3001
