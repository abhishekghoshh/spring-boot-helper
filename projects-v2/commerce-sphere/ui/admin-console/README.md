# CommerceSphere Admin Console

React 19 admin dashboard for managing the CommerceSphere platform.

## Pages
- Login
- Dashboard (stats: products, categories, brands, users)
- Products (CRUD with search/filter)
- Categories & Brands (CRUD)
- Inventory Management
- Orders (list & detail)
- Customers (list)
- Settings (password change)

## Running Locally
```bash
cd ui/admin-console
npm install
npm run dev
```

Access at http://localhost:3000
Default admin: admin / Admin@123
